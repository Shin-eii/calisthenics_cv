# Calisthenics Pose Tracker

This is a computer vision project that uses Python to track and evaluate calisthenics movements, such as the Frog Stand. 

## Features
* Live webcam pose detection.
* Video file analysis.
* Built using OpenCV and MediaPipe.

1. Ensure you have Python installed.
